## Висновки за результатами порівняння

Сортування вставками має складність `O(n²)`, тому на великих випадкових і зворотно
впорядкованих масивах його час зростає найшвидше. На вже відсортованих даних
алгоритм може працювати близько до `O(n)`.

Сортування злиттям має стабільну складність `O(n log n)` для різних наборів даних.
Воно помітно ефективніше за сортування вставками на великих масивах, але створює
додаткові списки під час злиття.

Вбудований `sorted` використовує Timsort — поєднання сортування злиттям та
вставками. Він використовує вже впорядковані фрагменти даних, тому зазвичай є
найшвидшим або близьким до найшвидшого алгоритмом у всіх перевірених випадках.
Практичні вимірювання підтверджують теоретичні оцінки, тому для реальних задач
доцільно використовувати вбудоване сортування Python.
